# RA8 下位机固件

在 e2 studio + FSP 中按板型新建工程，加入 `protocol.h`，实现下列模块。

## 模块

| 模块 | 职责 | 周期 / 触发 |
| --- | --- | --- |
| 电机 PID | 编码器 → 左右轮速闭环 → 驱动 PWM | 1 kHz |
| 循迹 | 8 路灰度 → 横向偏差 → PD 差速 | 100 Hz |
| 避障 | 前/左/右超声波 → 减速 / 绕行 / 回线 | 20–50 Hz |
| 机械臂 | 四路舵机 PWM；抓取 / 投放角度序列 | 事件 |
| 语音 | SYN6288 串口播报 | 事件 |
| 协议 | 解析下行，上报里程 / 循迹 / 避障 / 臂 / 语音 | UART 中断 + 周期 |

## 安全

1. 500 ms 无下行帧 → 电机 PWM 归零（急停）  
2. SET_MODE=急停立即停车并保持  
3. 速度斜坡限制，避免冲击  
4. 机械臂序列中夹爪动作失败时上报 `ok=0`  

## 建议调试顺序

1. 串口回环 + HEARTBEAT  
2. 单电机开环 → 编码器方向 → 速度 PID  
3. 灰度循迹直线与弯道  
4. 超声波避障与回线  
5. 舵机单关节 → 抓取 / 投放序列  
6. SYN6288 播报
