# 接线表（循迹 / 避障 / 机械臂 / 语音）

## 电源

| 从 | 到 | 说明 |
| --- | --- | --- |
| 电池组（按电机额定电压） | 电机驱动 VM | 电机动力电 |
| 电池 → 稳压 | OrangePi AIpro | 按官方规格给足电流，独立一路 |
| 稳压 5V | RA8 开发板 / 舵机电源（大电流舵机建议单独 BEC） | 逻辑与舵机供电隔离时注意共地 |
| — | — | **所有地必须共地** |

## RA8 ↔ 底盘

| RA8 | 外设 | 说明 |
| --- | --- | --- |
| GPT PWM ×2 + GPIO 方向 | TB6612 / AT8236 | 左右侧电机 |
| 输入捕获 / 外部中断 | 编码器 A/B ×4 | 里程计与速度闭环 |

## RA8 ↔ 传感器

| 外设 | 接口 | 说明 |
| --- | --- | --- |
| 8 路灰度阵列 | ADC ×8 或数字比较输出 | 车头底部跨线安装 |
| 超声波 ×3（前/左/右） | GPIO 触发 + 回波测宽 | 避障主传感器 |
| 红外近距（可选） | GPIO | 补充近距离 |

## RA8 ↔ 执行机构

| 外设 | 接口 | 说明 |
| --- | --- | --- |
| 四路舵机 | PWM ×4 | 底座 / 大臂 / 小臂 / 夹爪 |
| SYN6288 | UART（独立或复用） | 中文语音合成 + 喇叭 |
