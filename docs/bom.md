## 下单顺序（重要）

1. **A 供电** → 到货后按 `power_design.md` 测 5V  
2. **B 底盘 + 驱动** → 能转轮  
3. **C3 雷达 X3** → 香橙派上出图  
4. **D 臂 + 语音** → 定点抓取  
5. **E 结构** → 边装边改孔位
