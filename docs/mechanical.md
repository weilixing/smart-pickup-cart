# 机械与场地规格（按开题报告方案）

## 场地

- 约 3 m × 3 m 室内硬地面  
- 黑色引导线铺设路线：出发点 → 取货点 → 投放点 → 返回出发点  
- 取货点、投放点可用色标 / RFID / 灰度特征做站点识别（联调时再定）

## 货物

- 规则货箱：约 80–120 mm 见方，质量 ≤ 300 g（适配舵机夹爪）  
- 取货位高度与机械臂工作空间匹配（示教时标定）

## 车体与底盘

| 项目 | 建议值 | 说明 |
| --- | --- | --- |
| 甲板 | 200 × 160 mm | 亚克力 / 铝板 |
| 驱动 | 4WD 差速 + 编码器电机 | MG513 级别 |
| 车轮 | Ø65–85 mm | 按采购成品 |
| 循迹 | 8 路灰度阵列，车头底部 | 跨线布置 |
| 避障 | 超声波前 + 左右；红外近距补充 | 探头朝外 |
| 机械臂 | 四自由度舵机臂，装于甲板前部或中部 | 底座 / 大臂 / 小臂 / 夹爪 |
| 语音 | SYN6288 + 喇叭 | 固定于甲板 |

## 机械臂（四自由度）

关节约定（URDF / 固件统一）：

1. `base_yaw`：底座水平回转  
2. `shoulder`：大臂俯仰  
3. `elbow`：小臂俯仰  
4. `gripper`：夹爪开合  

抓取与投放采用**预设舵机角度序列 + 示教标定**，一期不做视觉伺服。
