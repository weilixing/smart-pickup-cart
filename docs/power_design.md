# 供电设计（先于采购）

目标：OrangePi AIpro + RA8 + 电机 + 舵机臂 + YDLIDAR X3 + SYN6288，一路电池供电、分区稳压、共地、可急停。

## 1. 总体原则

1. **动力与逻辑隔离稳压**：电机/大电流舵机走动力电；OrangePi、雷达、逻辑板走稳压后的干净电。  
2. **必须共地**：所有电源负极接在同一点，否则串口/传感器会乱。  
3. **按峰值留余量**：舵机堵转、电机启动电流大，稳压和电池按 1.5～2 倍峰值估。  
4. **先断电再插拔**：特别是舵机、雷达 USB。

## 2. 推荐电池

| 项目 | 选型 | 说明 |
| --- | --- | --- |
| 电池 | **3S 锂电（11.1V 标称，满电约 12.6V）**，容量 **5200 mAh** 起 | 兼顾 12V 电机与降压余量 |
| 保护 | 带 BMS 的电池组，或外加防反接二极管/保险 | |
| 接口 | XT60 或 XT30 出线 | 大电流可靠 |
| 总开关 | 电池后串 **总电源开关 + 20A 保险** | 整车一键断电 |

续航粗估（演示用）：5200 mAh × 11.1V ≈ 57 Wh；整车平均 15～25 W 时，约 2～3 小时量级（仅作参考）。

> 若买的是 6V/7.4V 舵机套件，舵机不要直接挂 3S，见下文舵机供电。

## 3. 电源树

```
3S 电池 (11.1~12.6V)
   │
   ├─ 总开关 + 20A 保险
   │
   ├───────────── 动力干路 (约 12V) ─────────────
   │                 │
   │                 ├─ 电机驱动 VM（TB6612/BTS 等）
   │                 │
   │                 └─（可选）大电流舵机 BEC：12V→7.4V/6V 5~10A
   │
   └───────────── 逻辑干路 ────────────────────
                     │
                     ├─ 降压模块 A：12V → 5V/5A（或 OrangePi 官方要求的电压/电流）
                     │      └─ OrangePi AIpro 电源输入
                     │      └─ YDLIDAR X3（若 USB 供电不足，改由此 5V 供电）
                     │
                     ├─ 降压模块 B：12V → 5V/3A
                     │      └─ RA8 开发板 5V
                     │      └─ 灰度/超声等传感器 5V（本期可不用灰度）
                     │      └─ SYN6288 + 小喇叭（小电流）
                     │
                     └─（若舵机电流不大）同一 BEC 给舵机；推荐独立 BEC
```

**OrangePi AIpro 供电以官方手册为准**（常见为 Type-C 5V 大电流，或板载接口）。务必单独一路 5V，**不要和电机驱动共用一个小模块**。

## 6. 接线顺序（第一次上电）

1. 不接电机、不接舵机、不接 OrangePi。只接电池 → 开关 → 保险 → 两路降压，用万用表量 5V 是否正常。  
2. 接 RA8 5V，确认能烧录/跑灯。  
3. 接 OrangePi 专用 5V，确认能开机（电流足够，不会反复重启）。  
4. 接雷达 USB，`lsusb` 能看到设备。  
5. 最后接电机驱动与舵机 BEC；第一次上电手握总开关，发现异味/发热立刻断电。

## 7. 安全检查表

- [ ] 电池正极有保险  
- [ ] 动力地与逻辑地已共地  
- [ ] OrangePi 与电机不是同一个小降压模块  
- [ ] 舵机有独立 BEC，电压匹配舵机规格  
- [ ] 导线粗细足够（动力线明显粗于信号线）  
- [ ] 正极反接防护（接插件防呆）
